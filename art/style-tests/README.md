# Supe Pines style tests

These are two non-production tests for the Case **The Toll**. They use the same
scene so the visual treatment can be compared directly before the full art pack
is regenerated.

- `toll-bold-cartoon-comic.png` — bold cartoon comic-book treatment: thick
  expressive outlines, oversized shapes, flat punchy color, exaggerated poses,
  and playful but tense street-level menace.
- `toll-abstract-church-glass.png` — abstract church-window treatment:
  fragmented geometric panes, symbolic silhouettes, dark lead lines, vaulted
  symmetry, and luminous jewel-tone backlight.

Both intentionally avoid readable text, logos, captions, card frames, and
franchise-specific characters.

## Roster sample

The first three Heroes and first three Threats were generated in both
directions:

- `roster/bold-cartoon-comic/` — Ballast, Apex, The Pulse, The Sophist,
  Hemlock, and The Forge.
- `roster/abstract-church-glass/` — the same six subjects, translated into
  fragmented church-window geometry.

These remain style-test assets and do not replace the live `art/images/` slots
until the visual direction is approved.
